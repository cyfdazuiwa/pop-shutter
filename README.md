# 波普快门 POP SHUTTER 🎨📸

一个**波普艺术风格**的实时拍照网页：左侧是你的摄像头画面被渲染成 **4×5 = 20 宫格**的安迪·沃霍尔式动态波普画（颜色持续闪动切换）；右侧实时检测**焦躁指数**——指数冲过阈值时自动抓拍，照片滑入待选区，可单张下载或打包 ZIP。

> 核心体验：你只需「点开始」和「对镜头玩」，其余一切自动、静默、不打断地完成。

## 运行

摄像头权限要求页面运行在 `localhost` 或 HTTPS 下，所以请勿直接双击 index.html（file:// 打不开摄像头）。

**方式一（推荐）**：双击 `start.command`，会自动启动本地服务并打开浏览器。

**方式二**：在本目录执行

```bash
python3 -m http.server 8137
# 然后浏览器访问 http://127.0.0.1:8137
```

## 玩法

1. 点「开启摄像头，生成你的波普肖像」→ 允许摄像头权限；
2. 对镜头**快速晃头、瞪眼、做鬼脸**，右侧焦躁指数会实时跳动（绿 → 黄 → 红）；
3. 指数超过**触发阈值**（默认 80，滑块可在 0–100 间调节）：宫格白闪一下 + 咔嚓声，照片自动进入待选区；也可以随时按取景区下方的**圆形快门键手动拍摄**；
4. 悬停缩略图可**下载 / 删除**，单击**放大预览**；底部可**全部下载 ZIP** 或**清空**；
5. 有未下载照片时关闭页面，浏览器会轻提醒一次。

### 画面风格自定义

右侧「画面风格」面板可自定义实时宫格效果（偏好存于本地，下次打开生效）：

- **宫格**：3×3（9 格）/ 4×5（20 格）/ 5×6（30 格），即时切换；
- **波普风格**：
  - *套色经典*：灰度海报化后按色系随机套色，各格独立闪切（安迪·沃霍尔式）；
  - *原彩波普*：保留真实色彩，逐格做色相旋转 + 饱和强化 + 色阶压缩，形成六十一变的多彩效果；
- **色系**（套色经典模式下可选）：沃霍尔 / 霓虹 / 糖果 / 黑白，或选「自定义」用三个取色器指定亮部 / 中间调 / 暗部，全宫格统一套色。

### 照片样式自定义

右侧「照片样式」面板可自定义出片效果，改动对**已拍照片即时生效**（重新合成，下载也按新样式导出）：

- **边框**：拍立得（白框厚底）/ 暗房（黑框画廊感）/ 极简（细白边）；
- **标注文字**：底部手写体一句话，默认 "Own your restless face."，可随意改；
- **焦躁值印章**：右下角红色邮戳式「焦躁指数」印章，可开关；
- **日期**：拍摄时间，可开关；
- **所见即所得**：取景画面直接套用所选边框、标注与印章，看到的 preview 就是成片；面板左侧另有小预览（相机开启后跟随宫格画面实时刷新）。

偏好保存在浏览器本地（localStorage），下次打开仍生效。

### 防刷屏机制

- **冷却**：触发一次后 4 秒内不会重复触发；
- **连拍择优**：指数超标期间每秒静默抓一帧，待指数回落，只保留其中**指数最高的一帧**入册，全程无感。

## 隐私

- 纯前端实现：`getUserMedia` + `face-api.js` + Canvas 全部在浏览器本地完成；
- 照片仅存在于当前页面的内存中，**不上传任何服务器**；刷新页面即清空。

## 技术要点

| 模块 | 实现 |
|---|---|
| 波普宫格 | 单 Canvas：视频帧镜像裁切 → 灰阶强对比 → 亮度三分档 → 每格独立 14 套沃霍尔配色 LUT 查表上色，随机间隔独立换色 |
| 焦躁指数 | face-api.js Tiny 人脸检测 + 68 点关键点 + 表情识别；综合「头部位移速度 / 水平晃动反转频率 / 偏航角 / 微表情强度」实时估算 |
| 自动抓拍 | 指数 EMA 升快落慢；超标触发抓拍（白闪 + WebAudio 合成快门音）+ 冷却 + 每秒静默连拍择优 |
| 相册 | 内存 Blob URL；JSZip 打包下载；beforeunload 轻提醒 |

依赖已全部本地化（`js/vendor/` 与 `models/`），**离线可用**。若模型加载失败，会自动降级为「简化模式」（基于画面运动占比估算指数），功能不受阻。

## 调试 API（控制台）

```js
PopApp.forceCapture()   // 手动触发一次抓拍
PopApp.photos           // 当前照片列表
PopApp.state            // 运行状态（指数、阈值、episode 等）
```
